# 轻启 · 新标签页 —— 全功能交互与视觉重设计稿（灵动通透桌面风）

> 对应真实工程路径：`vue-chrome-ext-client/src/newtab/components/redesign/*` + `styles/redesign/tokens.css`
> 设计风格定位：**对标国内主流新标签页（iTab / WeTab / Infinity / 鸿蒙桌面美学）—— 灵动通透毛玻璃 + 8×2 大圆角 App 图标宫格 + 精致卡片双态切换 + 农历节气本土化体验**
> 本次更新重点：**页面上每一个可点击的入口都真实可用，并且全部状态在刷新 / 重开浏览器 / 切换外观后都不会回退。**

## 一、原版核心痛点诊断与重设计方案

### 1. 原版存在的严重视觉与可读性缺陷
1. **CSS 继承链导致多处「白底白字」与「暗景黑字」严重事故**：
   - 原版在 `body.photo-tone-dark` 下将 `body` 的 `color` 计算为 `#ffffff`，而 `.header-tabs`、`.searchbox`、`.quick-section` 等容器仅重定义了 `--ink` 变量却未显式声明 `color: var(--ink)`，导致页头导航（`收藏夹 / 历史记录 / 工具箱 / 稍后阅读`）、引擎名（`Bing`）、`快捷访问`、`编辑` 全部继承了纯白字叠在白色胶囊上，几乎完全不可读。
   - 原版在「暮色」「深夜」渐变预设下未切换场景层文字色调，导致时钟与一言呈现深藏青色叠在深色背景上的“反相残影”效果。
2. **快捷访问区域厚重沉闷、不符合国人桌面习惯**：
   - 原版采用大面积半透明灰褐色厚重外框 + 4 列超宽扁条磁贴，右侧大量留白浪费，暗红壁纸透色后呈现浑浊泥灰色；且 favicon 加载后在渐变色块中二次套白底小方框，视觉割裂。
3. **缺少中国用户高频刚需的本土化信息与精致图标**：
   - 缺少公历星期 + **中国农历日期与二十四节气**（国内新标签页高频刚需）；
   - 天气、工具箱、设置抽屉大量直接使用系统原生 Emoji（`⛅ 🧾 📱 🎬 🔊 ✂️`），在 Windows / Linux 下渲染粗糙廉价；
   - 侧库同步提示条写死浅绿 `#f0fdf4`，深色模式下刺眼突兀。
4. **交互「点到即止」、状态不落地**（本轮重点修复）：
   - 外观 / 布局 / 壁纸等切换只改当前 DOM，刷新即回到初始态；
   - 快捷访问「＋ 添加」固定插入示例站点、编辑只能删除不能改名改网址、无法拖拽排序；
   - 历史记录四个子标签点击无内容切换；稍后阅读只有静态条目；工具箱点击无响应（没有真正可用的小工具）；
   - 天气城市只能删不能自定义新增；待办只能新增不能编辑；账号 / 昵称 / 会员 / 登录态全部是死数据。

### 2. 本次重设计核心升级亮点

#### 2.1 双层色彩语义彻底解耦（根治对比度事故）
- **场景层令牌（`--scene-ink` / `--scene-ink-muted` / `--scene-shadow` / `--scene-pill-*`）**：专供直接落在壁纸或渐变上的品牌字、大时钟、公历农历副标题、一言及无框宫格文字；暗图 / 暮色 / 深夜 / 深色外观自动切换纯白柔光字，亮图（如内置「江南烟雨」壁纸）/ 晨雾 / 薄荷自动切换深黛字。
- **面板层令牌（`--ink*` / `--panel*`）**：专供页头胶囊、搜索栏、卡片、浮层、侧库与设置抽屉，所有面板显式声明 `color: var(--ink)`，与 `html.dark` 严格正交，十余种「壁纸/预设 × 浅色/深色外观」组合全部清晰通透。

#### 2.2 主流 8×2 大圆角 App 图标宫格 + 4×4 精致卡片一键切换
- **默认「App 图标宫格（8 列×2 行 = 16 项/页）」**：去除笨重外层大底板，采用 56px 超椭圆大圆角（Squircle）品牌渐变矢量图标 + 内高光微立体质感，让精美壁纸自然呼吸；
- **支持一键切换「精致毛玻璃卡片（4 列×4 行 = 16 项/页）」**：保留 16 项/页完全一致的分页与滑动逻辑，展示站点名称与域名副标题，工具栏与设置抽屉双向同步切换；
- 两种模式均完整支持：**鼠标滚轮翻页、指针拖拽阻尼翻页、底部灵动圆点指示器、右上按钮翻页、编辑态拖拽排序 / 修改 / 删除 / 新增网站**。

所有可切换状态统一写入 `localStorage`（键名 `qingqi_newtab_state_v2`），首帧前由内联脚本恢复深浅色，彻底消除刷新闪白与状态回退：

| 分类 | 持久化内容 |
| --- | --- |
| 外观 | 浅色玻璃 / 深色曜石 / 跟随系统（含系统外观实时跟随）、流体渐变预设与图片壁纸选择 |
| 壁纸 | 内置 5 张高清壁纸选择、本地上传壁纸（自动压缩后以 JPG DataURL 存储）、模糊度（0–20px）、遮罩浓度（0–70%） |
| 布局 | 图标宫格 / 胶囊卡片、链接打开方式（新标签页 / 当前页 / 新窗口）、时钟秒数、页头状态条、底部快捷键提示 |
| 内容 | 快捷访问站点（增删改 + 排序）、收藏夹目录与书签、历史记录 / 标签组 / 最近关闭 / 会话快照、稍后阅读（含阅读进度）、随手便签、待办日程、便签昵称与会员、常用城市与当前城市 |
| 其他 | 快捷访问分页、侧栏宽度（200–1000px）、隐私空间密码与私密内容、搜索历史、状态快切栏折叠态 |

#### 2.5 内置真实可用的本地工具（零依赖，纯前端实现）
1. **JSON 格式化与校验**：原地解析、美化缩进、压缩一行、错误行列定位、复制结果。
2. **网址与文本二维码**：自研 QR Code 编码器（Byte 模式 / 纠错 L / 版本 1–6 / 掩码 0），**逐模块与业界 `qrcode` 库比对 0 差异**，支持尺寸调节与 PNG 导出。
3. **MP4 无损提取音频**：`decodeAudioData` 本地解码音轨 → 波形绘制 → 试听 → 导出无损 PCM WAV。
4. **音频人声智能放大**：100%–300% 增益 + 动态压缩（阈值 -18dB / 4:1）实时试听，离线渲染导出。
5. **MP3 可视化波形剪辑**：真实声波绘制、起止区间裁剪、选区试听与导出。

#### 2.6 全量本土化细节与全矢量图标重绘
- **灵动主次时钟 + 公历星期 + 干支农历与二十四节气**：大字号时分（`HH:MM`）搭配轻量化秒数（`:SS`，可关闭）；页头、欢迎区、日历月视图全量接入纯原生零依赖中国农历与二十四节气（如 `寒露`、`霜降`、初一月份高亮、周末红字提示）。
- **聚合搜索引擎**：内置 **必应、百度、Google、B站、知乎、搜狗、360搜索、DuckDuckGo** 矢量品牌图标与下拉面板，自动识别 Windows（`Ctrl + K`）与 macOS（`⌘ K`）。
- **全量清除 Emoji 与写死色值**：重绘多色矢量天气图标、工具箱双色分类图标、17+ 高频网站精绘品牌图标；历史硬编码颜色全部收敛至 `:root` / `html.dark` 令牌。

## 二、快速预览方式

- 直接双击打开 `index.html`（零依赖，兼容 `file://` 本地协议）；
- 或启动本地静态服务（Canvas 壁纸像素明暗采样需要 `http://` 环境）：
  ```bash
  python3 -m http.server 5199
  ```
  浏览器访问 `http://127.0.0.1:5199` 即可体验全部交互。

### 快捷键一览
| 快捷键 | 行为 |
| --- | --- |
| `Ctrl + K` / `⌘ K` / `/` | 聚焦搜索并展示最近搜索建议 |
| `Alt + Q` | 打开隐私空间（本地密码保护） |
| `Alt + S` | 打开效率工具箱 |
| `Esc` | 逐层收起：弹窗 → 抽屉 → 浮层 → 编辑态 |
| `⌘/Ctrl + Enter` | 便签输入框内快速保存 |
