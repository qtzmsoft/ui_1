# 轻启 · 新标签页 —— UI 美化参考 Demo

> 目录：`ui/20261022/` ｜ 生成日期：2026-10-22 ｜ 用途：**给美工做视觉美化的静态基准稿**

## 一、这是什么

把当前系统（`vue-chrome-ext-client/src/newtab/components/redesign/`）的新标签页**逐组件原样复刻**成一份零依赖静态页面：
HTML 结构、CSS 令牌、字号、圆角、透明度、层级、交互状态都与现行代码一致，**没有做任何"美化"改动**。

美工在这份稿子上改视觉 → 回交后我再按真实组件（Vue scoped 样式 + `styles/redesign/tokens.css`）逐项落地。

## 二、怎么打开

- 直接双击 `index.html`（本地文件协议即可，无需构建、无需依赖）；
- 或起静态服务：`python -m http.server 5199` → `http://127.0.0.1:5199/index.html`。

> **建议用静态服务打开**：`file://` 协议下浏览器禁止读取画布像素，壁纸「明暗采样」会走兜底档（中强深色蒙层 + 图上浅字）。
> 本张壁纸实测偏暗（采样亮度 56），兜底结果与真实档一致，所以两种打开方式观感相同；换亮图时请走 http。

壁纸已下载到本地 `assets/wallpaper.webp`（离线可看；读取失败会自动回退远程地址）。
注意：图床原文件实际是 WEBP 编码，扩展名虽写作 `.png`，已按真实格式改名为 `.webp`。

## 四、页面底部「演示条」不是系统 UI

底部那条蓝色标签写着 **「演示 · 非系统 UI」** 的工具条，只用于切换状态给美工看效果，**真实产品里没有这个条**，美化时请忽略它（或告诉我需要一并美化成调试面板）。

可切换的状态：

- 场景：图片壁纸 / 晨雾渐变 / 暮色 / 薄荷 / 深夜
- 外观：浅色 ↔ 深色（与场景正交，深色走 `html.dark` 令牌）
- 侧库四个 pane：收藏夹 / 历史记录 / 工具箱 / 稍后阅读（推挤式布局，主内容会右移让位）
- 浮层：天气 / 日历与任务 / 账号 / 搜索引擎菜单 / more 菜单
- 设置抽屉、快捷访问编辑态（摇晃 + × 删除 + 拖拽排序提示）

## 五、现行视觉口径要点（美化时请留意，别改坏逻辑）

1. **玻璃层级是三级令牌**：`--panel-soft`（卡片）< `--panel`（容器）< `--panel-strong`（强调控件 / 浮层）。图片壁纸态下容器降到 `.34`、卡片 `.18`，刻意"透色不透形"，让壁纸透出来；小面积胶囊（页头导航、天气日期、图标按钮、页脚胶囊）另提到 `.9` 保可读。
2. **两套明暗语义分离**：
   - `body.photo-tone-dark / light`：由壁纸亮度采样决定，**只作用于直接压在图片上的文字**（时钟、一言）；
   - `body.rd-photo`：面板容器恒定深字（浅色外观）/ 浅字（深色外观），**不参与读图**。
   美化时若新增以 `--panel*` 为底的容器，必须同步登记到 `styles.css` 里那份「面板内部文字」清单，否则会复现"白面板白字"。
3. **颜色预设与深浅外观正交**：主题只改色相（`theme-dusk/mint/night`），深浅由 `html.dark` 统一驱动。
4. **快捷访问隐私项隔离**：主网格任何状态（含编辑态）都不显示隐私项，只在 Alt+Q 面板管理——本 demo 未渲染隐私项，属有意为之。
5. **日历与天气是两个独立入口**（页头中部两段按钮 + 分隔点），不要合并成单个按钮。
6. **今日未完成任务徽标常驻**（日期右侧红色数字，99+ 截断）。
7. **任务类型配色语义**：工作=绿（`--success`）、会议=暖棕（`--warn`）、个人=紫（`--accent-personal`）。
8. 页头导航点击已激活页签 = 收起侧库；侧库宽度可拖拽（200–1000px，默认 312px）。

## 六、demo 与真实代码的已知差异（不影响美化判断）

| 差异 | 原因 |
| --- | --- |
| 数据全是假数据（快捷访问 17 项、天气、任务、历史、收藏树） | 静态 demo 不接服务端 |
| 快捷访问图标 = 首字母渐变底，favicon 探测成功后才替换为图标 | 与真实链路同语义（真实为 `imageUrl → 后台抓取 → origin/favicon → 首字母`），离线打开也不会出现破图 |
| 侧库「收藏夹 / 历史记录」pane 是结构示意 | 真实页面内嵌既有 `BookmarkTree` / 历史五视图组件，内部细节较多；美化时按壳层 + 列表节奏改即可 |
| 「隐私快捷访问」「添加网站」表单弹窗、壁纸库浮层页、Toast、二次确认未渲染 | 属独立浮层，需要时可另出一版 demo |
| 主题切换按钮（设置抽屉「外观模式」）用了 `--surface-2/--border/--primary` 等历史令牌 | 真实项目里这些令牌在 redesign 下**未定义**（静默回退），demo 已补别名并在 `styles.css` 顶部标注；代码化时需统一为 redesign 令牌 |
